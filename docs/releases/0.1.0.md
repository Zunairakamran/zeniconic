# Zeniconic 0.1.0

First Windows build. Local-first, single-user, no account.

## Download

`Zeniconic-Setup-0.1.0-x64.exe` (≈156 MB), Windows 10/11 x64.

Windows SmartScreen will warn until the installer is code-signed: **More info → Run
anyway**. The publisher line reads *Unknown publisher* for the same reason.

## What works

- **Footage intake** — pick a folder of clips; one decode pass scores sharpness,
  shake, exposure and motion.
- **Vision tagging** — room, camera move, selling points and defects per shot, with a
  per-listing cost estimate ($0.1422 for 24 shots).
- **Planning** — three looks (Calm, Walkthrough, Social), each a full 30-second edit
  with hook, room order, price card and end card.
- **Variants** — approve or reject each look; export only what is approved.
- **Voice** — the agent's own lines restored from presenter windows, bridged with a
  local Kokoro voice, ducked under a music bed. Settings offers a one-click,
  checksummed, resumable 92 MB model download; a dropped connection or a closed app
  resumes from the byte already on disk. Until it is installed, exports use music
  and say so.
- **Captions** — Bricolage Grotesque 800, uppercase, centred, two lines maximum, no
  background plate, accent on the most substantial word.
- **Export** — 9:16, 16:9 and 1:1 from one edit; measured two-pass loudness
  (−14 LUFS vertical, −16 landscape); SRT and cover JPG beside the MP4; 30.000 s
  verified to ±0.1 s.
- **Review gate** — duration, black frames, freeze, hook visibility, loudness,
  safe-area text, CTA legibility, room order, repeated shots, facts present. A hard
  failure deletes the file instead of shipping it.
- **Chat refine** — ask for a change, get a diff against the edit, apply it.
- **Settings** — OpenRouter key in Windows credential storage, real data folder and
  version, and a one-click Kokoro voice model (92 MB, checksummed, resumable).
  Nothing is written to a listing, log or the installer.
- **Updates** — checks GitHub Releases on launch and prompts before restarting.

## Known limitations

- Installer is not code-signed (SmartScreen warning on first install and each update).
- The voice model is a separate download in Settings (92 MB). A first export before
  installing it uses the bundled music bed and says why.
- Arabic voice is specified but no engine ships.
- Job queue is in memory; closing the app cancels queued work.
- Batch export and the shot-review screen still use demo data in this build.
- Analysis sends derivative frames and short audio slices to the model provider.
  Footage itself stays on the machine.

## Verify after install

1. Launch → the brand ident plays, then the app opens.
2. Settings → paste an OpenRouter key → badge shows **Configured**.
3. New video → folder → facts (AED accepted) → Analyse.
4. Approve a variant → Export → files in
   `%APPDATA%\Zeniconic\data\listings\<slug>\exports\`.

## Checks run on this build

- `npx tsc --noEmit` clean; 820 unit and integration tests.
- 66/66 headless-Chrome route checks; both themes pass WCAG 2.2 AA.
- Real listing: vertical and landscape exports, 30.000 s, audio present, captions in
  frame, `.srt` and cover written, 11 min 40 s total.
- Packaged fallback: captions and overlay text burned with FFmpeg when the Remotion
  path is unavailable.
- Voice model downloader: resume after a dropped connection, HTTP Range from the
  partial byte count, checksum rejection, pause without deleting the partial, and a
  corrupted cache regenerated. The packaged app ships the ONNX runtime, so the
  download is usable without a development checkout.
