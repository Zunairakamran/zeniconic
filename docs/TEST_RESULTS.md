### Phase 6 — reliability and bug sweep (earlier in this session)

Bugs found and fixed in the reliability pass (Phase 6):

1. Remix service read `shot.id` from a `Shot`, which only has `index` — every
   analyse threw. Fixed to `sh{index+1}`; caught by the remix smoke.
2. The EDL gap rule rejected a deliberate jump inside one imported remix file.
   It now keys on `sourceId` + `src`; legacy same-source gaps still fail.
3. `retime` changed the scalar speed of a speed-ramped clip, invalidating the
   EDL. Ramped clips are skipped when growing the timeline.
4. A transition could demand a source handle from a ramped clip, which the
   renderer refuses. The capability now refuses first with a clear message.
5. The Analysis screen rendered progress from any job; a stale event could make
   a new analysis look complete. Events are filtered by `analysisJobId`.
6. `analysis:start` left a queued job behind if preparation failed. The job is
   now cancelled and the error surfaced.
7. Resumed analysis jobs never updated the listing status. Resume now writes
   ready/failed/draft like the live path.
8. Budget caps were not enforced before agent runs or tagging batches. Both now
   call the persisted ledger pre-flight.
9. The browser tagging toggle appeared to persist. It now reports that the
   setting needs the desktop app.
10. Studio voice spend was invisible. The voice stage returns provider and
    characters; exports record a character-rate estimate in the ledger (cached
    lines are included, so it is an upper bound rather than the invoice).
